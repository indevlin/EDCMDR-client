# Getting started

## Download

Get the client from [edcmdr.com/client](https://edcmdr.com/client) or from the
[releases page](https://github.com/indevlin/EDCMDR-client/releases). Only these downloads can
publish to ED Commanders.

| System | File |
|---|---|
| Windows | `EDCMDR-<version>-windows.exe` |
| Linux | `EDCMDR-<version>-linux` (make it executable: `chmod +x`) |
| macOS (Apple silicon) | `EDCMDR-<version>-macos.zip` (unzip, then open EDCMDR) |

Nothing to install: run the file. On Linux it works on any recent distribution, Steam/Proton
included.

## First run

1. The settings window opens. On **Commanders**, check that your journal folder is listed; the
   client finds the usual Windows and Steam/Proton folders on its own. If yours is elsewhere, press
   **Add folder…**.
2. Your commanders appear once their journals are read. Several commanders, or several folders,
   are fine.
3. On **Sharing**, pick a commander and switch on what you want on the site (see [[Sharing|Sharing]]).
4. Close the window. The client keeps running in the tray.

## The tray

Right-click the tray icon:

- **Pause** stops sending; **Resume** carries on.
- **Stop** stops sending until you start it again.
- **Push now** sends any changes straight away.
- **Settings…** opens the settings window.
- **Exit** closes the client.

**Linux:** KDE, XFCE, Cinnamon and X11 trays work as they are. GNOME needs the AppIndicator
extension. With no tray at all, the settings window stays open instead, and closing it exits.

## Updates

When a newer version is out, the tray menu and the status line in Settings say so. Download it from
[edcmdr.com/client](https://edcmdr.com/client) and replace the old file.
