# Troubleshooting

**No commanders listed.** Check the journal folder on **Commanders**. The game writes journals to
`Saved Games\Frontier Developments\Elite Dangerous` on Windows; on Linux with Steam/Proton, inside
the game's Proton prefix under `steamuser/Saved Games/Frontier Developments/Elite Dangerous`.

**"Standing by: another EDCMDR publisher is running on this computer."** EDLD or another copy of
the client is already publishing. Only one publishes at a time; that is fine.

**My page still shows "In game".** It turns to offline within a few minutes of the client stopping.
Presence must be switched on in **Sharing** for the page to show it at all.

**My page is out of date.** Sections with a delay appear when it runs out. **Push now** sends
changes at once; the site's leaderboards rebuild every ten minutes.

**"Update the EDCMDR client."** The site needs a newer version: download it from
[edcmdr.com/client](https://edcmdr.com/client).

**Verification failed.** See [[Verify with Frontier|Verify-With-Frontier]]. If Frontier's service is
down, wait and press **Verify with Frontier…** again.

Still stuck? Open an issue on [GitHub](https://github.com/indevlin/EDCMDR-client/issues).
